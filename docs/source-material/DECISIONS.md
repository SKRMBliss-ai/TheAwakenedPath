# Decisions

## Product positioning

**Decision:** Position the product as a Personal Practice Gym for the Mind rather than primarily as an emotional-awareness app, habit tracker, or generic mental-wellness app.

## Core loop

**Decision:** Centre the product around:

```text
Life happens
→ Notice something is stuck
→ Bring it to the gym
→ Understand the situation
→ Create a bespoke practice
→ Practise
→ Notice what happens inside
→ Try a different response
→ Build inner strength
→ Return to real life
→ Practise again
```

## Reusable engine

**Decision:** Build one reusable Practice Room engine rather than separate implementations for every emotional topic.

## AI positioning

**Decision:** Use the term **My Practice Coach** rather than positioning the AI simply as a psychological expert. The coach should not diagnose.

## Progress

**Decision:** Measure practice rather than morality or an objective-sounding “emotional health” percentage.

## Philosophy

**Decision:** Tolle- and Singer-inspired concepts can inform the design philosophy, while avoiding repeated attribution or presenting philosophical material as clinical/scientific authority.
