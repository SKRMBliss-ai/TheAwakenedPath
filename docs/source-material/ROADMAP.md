# Roadmap

This roadmap is derived from the product direction in the supplied document. Exact implementation order should be confirmed against the repository's actual current state.

## Foundation

- Establish the Practice Room engine.
- Define the reusable Practice Room data model.
- Protect the distinction between content/configuration and software primitives.
- Establish Kids Gym and Adult Gym as distinct experiences.

## Practice capabilities

- Situation intake.
- Event/thought/feeling/body/urge exploration.
- Awareness and observer exercises.
- Pause and choice exercises.
- Perspective exercises.
- Reflection and learning.
- Practice progress.

## Personalisation

- Bespoke Practice Rooms.
- Daily practice generation when nothing specific is bothering the user.
- Saved practices.
- Practice modification.
- Practice pause/resume.
- Completion.
- Multi-day challenges.

## AI Practice Coach

- Clarifying questions.
- Pattern identification.
- Structured practice generation.
- Exercise suggestions.
- Reflection.
- Progress support.
- Perspective exploration.

## Long-term experience

- Personal Practice Profile.
- Practice Journey.
- Areas being practised.
- Strengths being developed through practice.
