# Mind Gym — Voice Script

**Everything spoken in the app, in recording order.** Two voices: **you** (the narrator) and **Chirpy**.

**Owner:** Sim · **Last updated:** 3 September 2026
**Companion to:** `MIND_GYM_AUDIO_SPEC.md` (sound) · `MIND_GYM_TEACHING_MOVES.md` (where the lines come from)

---

## Before you record

**No line contains a name.** Not the child's, not Chirpy's. A recorded line can't say a name you don't
know yet, so names appear on screen only. If you ever put one into a spoken line, that line stops being
recordable.

**179 lines total.** Three or four sittings, not one. Recording tired is audible, and children hear it
before adults do.

| Tier | What | Lines | Why |
|---|---|---|---|
| 1 | Sessions 1, 2, 5, 6 | 72 | The intro, the smoke alarm, the closing teachings, Chirpy. If only these are your real voice, the app already sounds human. |
| 2 | Sessions 3, 4 | 43 | The questions and replies. Worth recording, but a clone would pass. |
| 3 | Sessions 7, 8 | 64 | Option labels and quiet-state takes. Clone them. Nobody will notice. |

**Setup:** one room, one mic position, one time of day. Your voice changes across a day and a week, and a
session recorded elsewhere won't cut against the rest. If you have to stop, finish a whole session first.

**Delivery overall:** warm, unhurried, adult. Never the children's-television voice — no sing-song, no
exaggerated brightness. Children read that as being talked down to by about six.

**Three takes of every line**, back to back, without stopping to judge. Choose later.

**File naming:** `<id>.wav`, exactly the ID below, lowercase. The app looks audio up by that ID, so a typo
is a silent line.

## Session 1 — Meeting the chatterbox

**Voice:** You — the narrator · **13 lines** · **Record first**

Plays once, on a child's very first go. The most important five minutes in the app: this is where the child discovers the voice in their head instead of being told about it. Unhurried. You are setting up a joke that lands in about ninety seconds.

| ID | Line | Delivery |
|---|---|---|
| `intro.01` | Hello! Want to try something a bit weird? | Warm, conspiratorial. Like you're about to share a secret. |
| `intro.02` | Make your head go quiet. Completely quiet. | Slow down here. |
| `intro.03` | No thinking at all. Not one single thought. | Straight, no wink. The child must believe it's possible. |
| `intro.04` | Ready? Off you go. |  |
| `intro.05` | Shhhhh… | Very soft. Sits under a ten-second countdown. |
| `intro.06` | So… did it stay quiet? | Genuine curiosity. Not knowing. Leave a beat before 'did'. |
| `intro.07` | Something started talking, didn't it. | Not a question. Delighted. |
| `intro.08` | Probably about how weird this was. | Dry. This is the joke — don't push it. |
| `intro.09` | It never stops. It's talking right now. About this. | Land 'right now'. |
| `intro.10` | This one lives on your shoulder. |  |
| `intro.11` | It talks all day long. It notices everything. |  |
| `intro.12` | And it gets things wrong all the time. | Fond, not critical. He's not in trouble. |
| `intro.13` | Give it a name. Any name you like. | Open, unhurried. Let them think. |

## Session 2 — The smoke alarm

**Voice:** You — the narrator · **7 lines** · **Record first**

Plays once, straight after the child names Chirpy. This decides whether the child keeps telling the app the truth. If it lands as 'you thought the wrong thing', the whole app becomes theatre. Warm and a bit funny throughout — never corrective.

| ID | Line | Delivery |

## When the recordings exist

Put the `.wav` files in one folder, convert to mono mp3 at 64 kbps, and the app's `say()` looks up
`AUDIO[id]` and plays the file, falling back to speech synthesis for any ID that isn't there yet. So you
can record in any order and ship partial — anything you haven't done keeps working in the robot voice.

About 179 lines at three seconds each is roughly nine minutes of audio, around 5 MB. Bundle it.
